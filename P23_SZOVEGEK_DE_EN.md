## Dashboard

**DE:**
Eine Oberfläche auf der alle wichtigen Daten auf einen Blick sichtbar sind. Finanzen, Bestellungen, Kundendaten, Statistiken. Alles wird automatisch aktualisiert, nichts muss manuell zusammengetragen werden. Von überall aus erreichbar, auch vom Handy. Layout und Inhalte sind frei anpassbar.

**EN:**
A single interface where all the important data is visible in one place. Finances, orders, customer data, statistics. Everything updates automatically, nothing needs to be collected manually. Accessible from anywhere, including mobile. The layout and content are fully customisable.

## AI chatbot

**DE:**
Existiert in zwei Formen. Nach außen: wird in die Webseite eingebaut und beantwortet eingehende Fragen automatisch — kennt Preise, Öffnungszeiten, Dienstleistungen, in mehreren Sprachen, rund um die Uhr. Was nicht beantwortet werden kann, wird weitergeleitet. Nach innen: unterstützt die Arbeit im Unternehmen — erstellt Zusammenfassungen, formuliert E-Mails, verarbeitet Dokumente, ordnet Daten.

**EN:**
Exists in two forms. Externally: built into the company website, it automatically answers incoming questions — knows prices, opening hours, services, in multiple languages, around the clock. What it cannot answer, it forwards. Internally: supports work within the company — creates summaries, drafts emails, processes documents, organises data.

## Automatizáció

**DE:**
In einem Unternehmen gibt es jede Menge kleine Aufgaben die immer gleich ablaufen. Eine E-Mail kommt rein, daraus müssen Daten entnommen, in eine Tabelle eingetragen und eine Bestätigung gesendet werden. Eine Bestellung kommt über den Webshop, das Team muss benachrichtigt und der Bestand aktualisiert werden. Ein Formular wird ausgefüllt, die Antworten müssen gespeichert werden. Diese Schritte lassen sich so verbinden, dass sie automatisch nacheinander ablaufen, ohne menschliches Eingreifen. Einmal aufgebaut, läuft es von alleine.

**EN:**
In any company there are countless small tasks that always go the same way. An email comes in, the data needs to be extracted, entered into a spreadsheet, and a confirmation sent back. An order comes through the webshop, the team needs to be notified and the stock updated. A form is filled in, the answers need to be saved. These steps can be connected so they run automatically one after another, without human intervention. It only needs to be set up once, then it runs on its own.

## Weboldal

**DE:**
Eine moderne Webseite die auf jeder Bildschirmgröße gut aussieht — Computer, Tablet, Handy. Sie lädt schnell, wird von Suchmaschinen gefunden. Funktioniert auch in mehreren Sprachen. Die Inhalte können über eine eigene Oberfläche bearbeitet werden, Änderungen erscheinen sofort.

**EN:**
A modern website that looks good on any screen size — computer, tablet, phone. It loads fast, search engines find it. It also works in multiple languages. The content can be edited through a separate interface, changes appear immediately.
